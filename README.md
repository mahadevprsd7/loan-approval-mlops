# Loan Approval Prediction MLOps Project

## Project Overview

This is an end-to-end MLOps project for predicting loan approval using Machine Learning.

## Technologies Used

- Python
- Flask
- Gradio
- Scikit-learn
- Docker
- GitHub
- CI/CD

## Features

- Loan Approval Prediction
- Flask REST API
- Gradio Web Interface
- Dockerized Application
- CI/CD Workflow
- Cloud Deployment Ready

## How To Run

### Install Requirements

pip install -r requirements.txt

### Run Flask App

python app.py

### Run Gradio App

python gradio_app.py
